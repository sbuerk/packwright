# sb-releaser

A PHP command-line application built on Symfony console components.

## Requirements

- PHP 8.2+

## Installation

Download the latest `sb-releaser` binary and make it executable:

```bash
chmod +x sb-releaser
```

## Usage

```bash
php sb-releaser <command>
```

List all available commands:

```bash
php sb-releaser list
```
